# Changelog

All notable changes to AlcoCraft+ are documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [2.2.0]
### Added
- The keg now exposes an item handler: ingredients can be inserted and extracted with hoppers and automation mods such as Create. Enables the Create: AlcoCraft+ addon.

### Fixed
- Keg brewing bubble animation now follows brewing progress instead of running at a frame-dependent speed.
- The keg now drops its contents when broken in creative mode.

## [2.1.1]
### Fixed
- Keg now renders correctly with shaders (Iris, Complementary). It previously relied on a block entity renderer and could appear invisible or glitched. Thanks to [Dalethium](https://github.com/Dalethium) for the fix.

## [2.1.0]
### Added
- Baseline release; start of this changelog.
